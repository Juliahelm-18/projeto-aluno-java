# Projetinho

Projeto simples em Java para praticar Comparable e Comparator

## Estrutura

- `Aluno.java` - Classe com nome, idade e notaFinal. Implementa Comparable para ordenar por notaFinal.
- `ComparadorPorNome.java` - Comparator para ordenar alunos por nome.
- `ComparadorPorIdade.java` - Comparator para ordenar alunos por idade.
- `Main.java` - Cria uma lista com 10 alunos, exibe a lista original e ordenada de tres formas diferentes.

## Como executar

1. Compile todos os arquivos:
   javac *.java

2. Execute a classe principal:
   java Main
